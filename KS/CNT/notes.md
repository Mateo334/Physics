# Notes — CNT Subfolder
## Scope for this subfolder

1. Mathematical setup: W*-dynamical systems, relative entropy, abelian models.
2. Full definition of the CNT entropy functional H_φ(N_1,...,N_k) and h_φ(Θ).
3. All main properties: positivity, subadditivity, monotonicity, Θ-invariance.
4. Key theorem: h_φ(shift) = mean entropy S(φ) for quantum spin chains.
5. Small explicit examples: qubit, qutrit with full matrix computations.
6. Python numerical verification.
7. Extensions and connections to AFL/OPU entropy studied in subfolder 1.
