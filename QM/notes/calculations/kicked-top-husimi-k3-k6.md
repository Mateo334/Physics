# Kicked-top Husimi phase-space densities at five kicks

[Numerically tested] `calculations/code/kicked_top_husimi_k3_k6.py` saves two images: `calculations/results/kicked_top_husimi_k3_t5.png` and `calculations/results/kicked_top_husimi_k6_t5.png`. Run from the workspace root with `py -3.13 calculations/code/kicked_top_husimi_k3_k6.py`. Uses spin j=20 (dimension 41), initial coherent state `exp(-i phi0 Jz) exp(-i theta0 Jy)|j,j>` with theta0=1.1 and phi0=0.7, and five repetitions of `U_k=exp(-ik Jz^2/(2j)) exp(-i pi Jy/2)`. No measurement backaction or initial-state averaging: both k values start from the *same* pure coherent state. Complex128 arithmetic, NumPy/SciPy/Matplotlib as in the four-model plot.

The spherical phase-space chart uses azimuth `q=phi` in [0,2pi) and conjugate normalized coordinate `p=cos(theta)` in [-1,1]; its poles have redundant azimuth. The plotted probability density is `Q_k(q,p)=(2j+1)/(4pi)|<theta,phi|psi_k(5)>|^2`, normalized with respect to `dq dp`. The spin-coherent resolution of identity fixes this prefactor. Both images share one color scale; the grid is 256 azimuth and 181 polar points. The same J_y and Floquet convention are used as in `calculations/code/compare_obsen_four_models_100_states.py`.

Checks: coherent-state binomial coefficients agree with two matrix exponentials at absolute tolerance 1e-11; state normalization, unitarity (1e-11), positive Q and numerical grid-integral estimates 0.999968 (k=3) and 1.000268 (k=6), with acceptance threshold 0.005. Both PNGs were visually inspected. The k=6 phase-space density appears more spread than k=3 for this one state and time; this is a finite-time illustration, not a proof of classical or quantum chaos. The pictures show a full spin Husimi distribution, not the earlier single-axis Jz outcome probabilities or observational entropy.

## Continuous sweep animation

The animation script is now `calculations/code/kicked_top_husimi_parameter_animation.py`. Its earlier version constructed 120 equally spaced k values from 3 to 6 and rendered an MP4 at 30 frames/s (4 s). **Each frame starts from the same initial coherent state**, evolves for exactly five kicks at its own fixed k, and evaluates the same spin-Husimi phase-space density on the same (q,p) grid. The density uses a single global color scale across all frames; interpolation is in the Hamiltonian parameter k, not physical time evolution between frames. The code propagates state vectors simultaneously and evaluates Husimi overlaps in 12-frame batches, without a GPU. It checks normalized evolved states, endpoint evolution against single-state loops and grid-integral error below 0.005. [Numerically tested] Matplotlib FFMpegWriter with ffmpeg/libx264 generated `calculations/results/kicked_top_husimi_k3_to_k6_t5_30fps.mp4` (226,659 bytes). Maximum grid-integral error across those frames: 0.000514614. `ffprobe` verified H.264-compatible 960x540, 30/1 fps and 120 frames; ffmpeg decoded the complete MP4 without an error. The earlier movie can be regenerated with `py -3.13 calculations/code/kicked_top_husimi_parameter_animation.py --resolution 540p --k-start 3 --k-stop 6 --fps 30` (defaults to four seconds).

## Higher-resolution version

The same 50-fps, four-second k=2..10 sweep was generated with a 512x361 (q,p) Husimi grid and 1920x1080 output, at H.264 quality CRF 18 instead of 20. The program performs a first pass to determine a common color scale and numerical normalization, then a second batched pass straight into ffmpeg, avoiding storage of all high-resolution densities. The `--resolution 540p` flag retains the old 256x181 grid and 960x540 output, so the existing movies remain reproducible. Output: `calculations/results/kicked_top_husimi_k2_to_k10_t5_50fps_1080p.mp4` (1,586,790 bytes); old video remains untouched. This improves displayed pixel and sampling resolution; it does not change spin j=20 or resolve physical phase-space structures below the coherent-state scale.
