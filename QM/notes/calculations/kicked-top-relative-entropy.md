## Repeated-measurement comparison

`calculations/code/kicked_top_repeated_measurement.py` separately applies the same nonselective, rank-one Jz projective measurement to each preparation at every time, then evolves the resulting dephased states with the same kicked-top unitary. It plots the KL divergence of the outcome distributions at each time (not the KL divergence of full measurement records). No outcome-conditioned trajectories are sampled. It uses j=10, epsilon=0.07, noise=0.3, 200 kicks, and kappa=4,6, matching the current direct-evolution script. The first measurement occurs at time zero. After the first rank-one measurement, both preparations' conditional state for a given outcome is the same projector; hence retaining the full outcome record would give a different statistic (its KL divergence stays equal to that of the first outcome distribution).

[Proved, previous fixed-Jz version] For a rank-one Jz measurement after each kick, the outcome probabilities satisfy `p(t+1)=M p(t)` and `q(t+1)=M q(t)` with `M_mn=|U_mn|^2`. Since `U=T_kappa R`, with `T_kappa=exp(-i kappa Jz^2/(2j))` diagonal in the Jz basis, `M_mn=|R_mn|^2` is exactly independent of kappa. That fixed-Jz protocol erased the twist's phases after every step. The marginal KL is nonincreasing by data processing; this is not a chaos-dependent Lyapunov rate. For rank-one measurements, the retained full-record KL stays at its first-measurement value even if the basis changes over time: the conditional post-measurement state is determined solely by the first outcome.

## Rank-m nonprojective POVM comparison

`calculations/code/kicked_top_rank_m_povm.py` is a separate, simple implementation matching the repeated random-basis script's *current* settings at creation: j=10, epsilon=0.07, noise=0.3, 5 kicks, kappa=(1.3,4,6,10). At each time it independently samples four rank-7 projectors P_i in d=21 with seed 20261116, then sets S=sum_i P_i and E_i=S^(-1/2) P_i S^(-1/2). For full-rank S, sum E_i=I and each effect has rank 7; the overlapping effects are generically not projectors. The same predetermined POVM is applied to both preparations at each time and all kappa values. Outcome probabilities are p_i=Tr(E_i rho), and the unrecorded Lüders update is rho -> sum_i sqrt(E_i) rho sqrt(E_i), followed by the kicked-top unitary. Thus the output is marginal outcome KL, **not** the relative entropy of full recorded histories. This rank-m POVM is not a weak/full-rank unsharp measurement: its effects still have kernels.

## Current fixed-POVM, conditional-history script

On the user's clarification, `calculations/code/kicked_top_rank_m_povm.py` now draws **one** rank-7 four-outcome random POVM at startup (seed 20261116) and reuses exactly this instrument for both preparations, all kappa values, and every kick. The first measurement occurs at t=0. It retains one outcome selected from the reference conditional probabilities p, conditions *both* states on that same recorded outcome via `rho -> K_a rho K_a†/p_a` and `sigma -> K_a sigma K_a†/q_a`, then applies the common unitary. A separate reference trajectory is sampled for each of the 100 initial pairs, with a reproducible outcome seed 20261118. No outcomes are averaged in the state update and the measurement does not change with time. The same sampled record need not have the same probability under both preparations. For each pair, the conditional KL at time t is `D(p(.|a_<t)||q(.|a_<t))`. The expectation under the reference process of the *cumulative sum* through t equals the full-record `D(P(a_0,...,a_t)||Q(a_0,...,a_t))` by the KL chain rule. The plotted 100-trajectory, 100-initial-pair average is therefore a Monte Carlo estimate of mean full-history KL, not exact full-history enumeration, not a single-time marginal KL, and not history observational entropy. Its value can fluctuate across seeds and may exceed an exact bound due to sampling error; the exact divergence is nondecreasing in record length.

## Current exact history distribution computation (supersedes sampled version)

The user clarified that the same fixed POVM acts independently on the two preparations, which need not produce matching records. The current `calculations/code/kicked_top_rank_m_povm.py` retains **all** branches of this fixed instrument, rather than forcing identical sampled records or averaging postmeasurement states. For a history `h=(a_0,...,a_t)`, its operator is `A_h=K_{a_t} U ... U K_{a_0}` and its respective probabilities are `P_rho(h)=Tr(A_h rho_0 A_h†)` and `P_sigma(h)=Tr(A_h sigma_0 A_h†)`. These are distinct probability distributions over the same set of records. Each iteration appends all four possible outcomes to every earlier history, then applies the common unitary before the next measurement. At t=5 there are 4^6=4096 histories. The script computes `D(P_rho^(t)||P_sigma^(t))` *exactly for this finite model* for each of the same 100 initial pairs, and then averages the resulting divergences; there is no measurement-record Monte Carlo error. The one fixed random rank-7 POVM (seed 20261116), state ensemble (seed 20261117), model parameters and t=0..5 are unchanged. The `kicked_top_fixed_rank_m_povm_histories_100_states.png` figure is from the earlier sampled conditional-trajectory version and is retained only as a historical result. Note: having the **same instrument** means the operators K_a are shared; it does not force equal outcomes in independent experimental realizations.

## Ordering correction: evolve then measure (current code)

The previous exact-history script measured immediately at t=0, then evolved before later measurements; the user requested the reverse order at every kick. The current script starts from each initial state and, for steps t=1,...,5, updates all history operators by `A_h -> U A_h` **before** appending each of the four measurement Kraus operators `K_i`: `A_(h,i)=K_i U A_h`. Thus the first recorded outcome occurs after one kick, and there are 4^t histories at the plotted time t; no t=0 measurement is performed. The fixed POVM and 100 initial pairs remain the same. ## Matched 100-state comparison: no backaction versus unrecorded backaction

The separate `calculations/code/kicked_top_fixed_povm_backaction_comparison.py` implements the user's two specified single-time measurement-distribution KL protocols side by side; it does **not** compute full-record KL. Both use identical 100 initial pairs (independent uniformly oriented spin-coherent directions, seed 20261117, rho=0.7|psi><psi|+0.3I/21, sigma=V rho V† with V=exp(-i0.07Jy)), one rank-7 four-outcome random POVM drawn once (seed 20261116), and the same kicked-top `U_kappa` with kappa=(1.3,4,6,10), evaluated at steps 1..20. In the no-backaction protocol, both states evolve unitarily and the outcome KL is calculated on separate copies at each t. In the backaction protocol each pair evolves by U, the same outcome KL is computed **before measurement**, and the nonselective Lüders map `L(tau)=sum_i sqrt(E_i) tau sqrt(E_i)` is then applied separately to each evolved state before the next kick. The fixed POVM alone would not uniquely specify an instrument; choosing Lüders operators K_i=sqrt(E_i) is an explicit extra assumption. All 100 individual KL values are averaged, not the probability vectors. Both protocols have the same first-kick value, asserted at 1e-12; neither is full recorded-history divergence and neither is observational entropy.
